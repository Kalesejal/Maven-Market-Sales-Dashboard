# 📊 Maven Market Sales Dashboard

## 📌 Project Overview
Maven Market Sales Dashboard is an interactive business intelligence project developed using Microsoft Power BI. It helps analyze sales performance, revenue trends, product profitability, and business targets through interactive visualizations.

## 🎯 Project Objectives
- Analyze overall sales performance.
- Track revenue and profit.
- Identify top-performing products.
- Understand geographical sales distribution.
- Compare revenue against targets.
- Monitor weekly revenue trends.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 📈 Dashboard Features
- KPI Cards for key business metrics.
- Product-wise Profit Analysis.
- Geographical Sales Analysis.
- Weekly Revenue Trend.
- Revenue vs Target Analysis.
- Interactive Slicers and Filters.
- Bookmarks for report navigation.

## 📂 Project Files
- `MavenMarket_Report.pbix` – Power BI dashboard file.
- `Dashboard_Screenshot.png` – Dashboard preview.

## 💡 Key Learning Outcomes
- Data cleaning and transformation using Power Query.
- Creating calculated columns and measures using DAX.
- Building data models and relationships.
- Designing interactive Power BI dashboards.
